# ounwan

친구들과 함께 사용하는 비공개 운동 인증 PWA입니다.

## 현재 범위

- Next.js + TypeScript + Tailwind CSS 기반 앱 골격
- 카카오 로그인, 저장소, 업로드, 서버 결산 로직은 아직 연결하지 않음
- 요구사항/목업 기준의 5개 주요 탭: 홈, 피드, 인증, 캘린더, 더보기
- 초기 서비스 모델은 시스템 전체에 하나의 시즌을 두지만, 데이터 모델은 향후 그룹별 시즌 확장을 고려해 `groupId`와 `seasonId`를 포함

## 확장 전제

초기에는 `CURRENT_GROUP_ID` 하나만 사용합니다. 추후 공개 배포 단계에서는 다음 구조로 확장할 수 있습니다.

- 사용자가 공개/비공개 그룹을 생성
- 사용자는 여러 그룹에 멤버십을 가짐
- 각 그룹은 하나의 활성 시즌을 가짐
- 게시물, 결산, 통장, 계좌 정보는 모두 그룹 단위로 분리

## 실행

```bash
npm install
npm run dev
```
